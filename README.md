# Portfolio

A polished and premium single-page portfolio for Sohaila Abdo.

## Structure

- `Portfolio/index.html` — main portfolio structure and content
- `Portfolio/styles.css` — premium design system, responsive UI, and motion styling
- `Portfolio/script.js` — scroll-triggered reveals, counter animations, and form validation
- `Portfolio/s.png` — profile image

## Preview

Open `Portfolio/index.html` in a browser to view the site locally.
